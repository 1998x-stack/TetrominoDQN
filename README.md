# 俄罗斯方块智能体训练系统（基于DQN）

🎮 一个基于深度强化学习（DQN）的俄罗斯方块训练平台，集成完整游戏环境、训练流程与模型管理，支持人机交互和视觉反馈，助力研究与教学。

---

## 🧠 系统简介

本项目构建了一个完整的俄罗斯方块训练系统，结合 PyTorch 实现的深度Q网络（DQN）算法，智能体可以在环境中自主学习并优化策略，实现从零开始的俄罗斯方块掌握过程。

系统模块包括：

- ✅ 游戏环境构建（符合 OpenAI Gym 接口）
- ✅ DQN 网络架构与优化策略
- ✅ 经验回放机制（Replay Buffer）
- ✅ 训练与测试流程可视化
- ✅ 配置灵活、界面友好、训练过程实时监控

---

## 🔧 功能亮点

- 🎮 **完整游戏体验**：支持键盘控制与训练过程自动演示
- 🤖 **DQN 智能体训练**：基于 PyTorch 框架实现
- 💾 **经验回放机制**：高效采样支持稳定训练
- 🧠 **训练状态监控**：输出实时进度与性能指标
- 🖥️ **图形化界面**：基于 Pygame 构建美观 UI
- ⚙️ **高度可配置**：所有参数集中管理，便于实验调参

```bash

cd tetris-dqn
pip install -r requirements.txt
````

## 🚀 快速开始

### 🔁 训练智能体

默认训练 1000 回合（每 50 回合渲染一次画面）：

```bash
python train.py
```

训练过程将实时输出以下信息：

* 回合数 / 得分 / 消除行数 / 当前等级
* 当前 ε-贪婪值（探索率）
* 当前平均损失 / 训练耗时

### 🧪 测试智能体

测试预训练模型需将 `train.py` 中的参数设置为：

```python
train_mode = False
```

确保模型路径有效，然后执行：

```bash
python train.py
```

## 🔍 关键模块概览

### `TetrisEnv`（游戏环境）

* 实现 `gym.Env` 接口
* 状态空间/动作空间标准化定义
* 支持方块生成、移动、旋转、判定、消行等逻辑

### `DQNAgent`（智能体）

* 基于 ε-greedy 策略选择动作
* 支持策略更新与模型保存/加载
* 内置 replay buffer 支持批量训练

### `ReplayBuffer`（经验回放）

* 使用 deque 实现
* 随机采样历史经验，防止相关性干扰
* 提供固定大小缓冲池，提高训练稳定性

### `DQN`（网络模型）

* 输入：游戏状态图像
* 输出：各动作的 Q 值
* 结构：卷积网络 + 全连接层

## 📈 模型监控与保存

训练过程中将自动保存模型文件至指定路径：

* `best_model.pth`：历史最优模型
* `final_model.pth`：最终模型
* `checkpoints/`：周期性保存的中间模型
